# 课堂第一段：成绩统计纠错

本案例是课堂两个演示中的第一段，之后继续演示照片整理。完整分工、时间安排和衔接讲法统一见 [两人课堂演示安排](../../../docs/CLASSROOM_GUIDE.md)。

操作顺序：读取程序和测试 → 运行并保留两项报错 → 只修复程序 → 复跑三项测试 → 解释平均分 85.0 和未填写 1 人。

讲解重点：Agent 怎样读取真实项目，怎样从测试失败得到反馈，怎样用修改后的实际结果证明这次修复有效。

同学的下载、开终端和切换第二案例步骤见 [上手指南](../../../docs/GETTING_STARTED.md)。本案例的具体话术见 [分步提示词](STUDENT_PROMPTS.md)。
