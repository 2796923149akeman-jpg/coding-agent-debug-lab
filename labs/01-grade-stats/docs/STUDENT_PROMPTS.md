# 交给 AI 的提示词

建议逐段发送，每段完成后先看结果。使用普通聊天 AI 时，由你在本地执行命令并把输出粘贴回来。

## 第一步：读项目（约 2 分钟）

```text
请先阅读 README.md、grade_stats.py、test_grade_stats.py 和 data/scores.csv，不要修改文件。
用三句话说明项目用途、主要文件的作用，以及测试命令。再说明预期业务规则。
```

## 第二步：复现（约 3 分钟）

```text
请运行 python -m unittest -v，给出真实测试结果，说明通过和报错的数量、错误位置以及原因。
先不要修改代码。如果你没有终端执行能力，请明确告知，并让我执行命令后提供输出，不要编造运行结果。
```

## 第三步：修复（约 5 分钟）

```text
请根据实际错误修复 grade_stats.py：
空白或只有空格的成绩要跳过，并计入未填写人数；有有效成绩时计算这些成绩的平均分，保留两位小数；全部空白时 average=None。
只修改 grade_stats.py。不要修改、删除或跳过原有测试，不要修改示例数据，不要硬编码结果，不要安装第三方依赖。
完成后重新运行 python -m unittest -v 和 python grade_stats.py data/scores.csv，报告真实输出。
如果不能执行，请提供完整的修改后文件和让我执行的命令，等待我的输出再判断是否通过。
```

## 第四步：人工验收（约 3 分钟）

```text
请展示代码差异，说明每处修改的作用。
用 80、空白、90 解释平均分为什么是 85.0，而不是把空白当成零分计算。
说明全部空白时的行为，以及为什么三个测试通过不等于任意输入都正确。
不要再修改文件。
```

## 一次性提示词（第二轮对比可用）

```text
这是一个 Python 成绩统计教学项目。请先阅读 README 和代码，实际运行现有测试，再定位问题。
要求空白或纯空格成绩不计入平均分并计入 missing；有效成绩平均分保留两位小数；全部空白时 average=None。
只修改 grade_stats.py，不得更改、删除或跳过原有测试，不修改示例数据，不增加第三方依赖。
修复后运行全部现有测试和示例程序，展示真实输出与代码差异。
最后解释 80、空白、90 的结果，并说明验证范围。
如果没有终端执行能力，请明确说明，并给出让我本地运行的命令，等待真实输出。
```

## 纠偏提示词

- 没有先测试：`请先复现初始报错，记录实际输出，再继续修复。`
- 改了测试：`请恢复原有测试和数据，只修复程序逻辑，然后重新运行。`
- 声称成功但无证据：`请提供实际执行命令、测试数量、退出状态和输出。无法执行时请明确说明。`
- 改动过多：`本轮仅处理空白成绩，请缩小改动范围，其他增强列为建议。`
