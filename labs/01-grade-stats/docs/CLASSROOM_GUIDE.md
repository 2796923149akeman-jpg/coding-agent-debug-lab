# 汇报结束后：让同学自己试一次

## 最后一页可增加的内容

标题：轮到你：让 AI 修复一个小项目

- 仓库：https://github.com/2796923149akeman-jpg/coding-agent-debug-lab
- 下载 → 解压 → 初始测试 → 让 AI 修复 → 复测 → 人工解释。
- 初始：1 项通过、2 项报错；结束：3 项通过。
- 验收样例：80、空白、90 → 平均 85.0，未填写 1 人。
- 关键约束：不能改测试、不能把 AI 预测当成实际运行。

## 20 分钟安排

| 时间 | 学生操作 | 汇报者观察 |
| --- | --- | --- |
| 0～3 分钟 | 下载解压，检查 Python，运行测试 | 是否进入正确文件夹，能否看到两项报错 |
| 3～6 分钟 | 让 AI 读项目、解释真实错误 | 是否先读先测，是否有事实依据 |
| 6～12 分钟 | 让 AI 修复并复测 | 是否只改程序，是否实际执行 |
| 12～16 分钟 | 运行示例、看差异、手算 | 是否为 85.0 和 1，测试是否原样保留 |
| 16～20 分钟 | 填写记录、分享结果 | 是否能解释修改及测试的局限 |

## 两人分工

- 介绍同学：在原汇报结尾介绍下载入口和 AI 辅助出题思路，收集练习感受。
- 演示同学：讲解运行命令、分步提示词和验收要求，协助解决目录与 Python 环境问题。

## 常见现场问题

- 找不到 Python：先完成 Python 安装和终端重开；可让两人共用一台已经准备好的电脑。
- `Ran 0 tests`：进入同时包含程序、测试和 data 文件夹的项目根目录。
- `not a git repository`：ZIP 解压没有 Git 历史，使用重新解压副本做文件对比和恢复即可。
- 一开始三项全通过：可能打开了已经修复的副本，重新下载到新目录。
- AI 一次就修好：继续让它解释差异、空白与零分的区别，以及测试遗漏的情况。
- 初始测试报错：这是练习设计；请核对是不是 `ValueError` 和两项报错，其他环境错误需先排除。
