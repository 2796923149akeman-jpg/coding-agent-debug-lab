# AI 辅助生成与材料来源

## 成绩统计

案例来自原《Coding Agents 两人汇报材料包》，程序、三个测试和示例数据保持原样。详见 [原案例生成与复现说明](../labs/01-grade-stats/docs/AI_GENERATION.md)。完整原始生成对话和精确模型版本未随材料提供，文中提示词是重建的复现版本。

## 照片整理

案例来自新增的《课堂实操包》。原包包含生成脚本、205 个输入文件、参考解答、答案索引、教师指南和演示记录。生成脚本使用 Python/Pillow 绘制渐变背景、色块、编号，生成截图、转存图片和异常占位文件；素材不是真实个人相册。

公开的 `data/photos.zip` 逐字节保留原包的 205 个输入文件。`manifest.json` 记录来源、哈希和统一修改时间，用于可靠下载、初始化和输入完整性核对。它不包含拍摄月份答案。

原包的生成脚本能说明数据是如何程序化构造的，但不能独立证明最初由哪个模型、在哪轮对话编写。原演示记录的环境和结果属于原包记录，本次不把它们当成本次执行证据。

本次由 AI 辅助完成仓库结构统一、操作说明、无覆盖素材初始化、自检工具加固和发布验证。参考答案与教师材料保留在本地，学生版没有参考整理实现。

## 生成同类练习的提示词（本次整理，非原始对话）

```text
请生成一个 Coding Agent 文件整理教学案例，使用纯合成素材，不使用真实个人照片。
交付学生版和教师版两个独立目录。
学生版包含 205 个扁平混杂文件、任务书、只检查输入输出的自检工具；不包含答案。
覆盖带 EXIF 的图片、无 EXIF 的截图和转存图片、占位视频、完全重复与近重复、无效日期、打不开的图片和系统残留。
所有文件统一修改时间，并记录一个能够在 Git 下载后恢复时间的素材清单。
学生任务是按年月归档、完整保留每个副本、禁止覆盖输入、输出逐文件清单、为重复提供证据。
教师版另给真值表和参考实现，实际执行后验证文件数量、逐内容副本数、可解码性和日期归档。
自检失败须返回非零退出码，缺失目录不能被视为通过；参考工具不能直接清空已有目录。
将真实运行输出与预期输出分开。不能执行时明确说明，不编造日志。
```

不同模型、Pillow 版本和字体环境生成的图片字节可能不同，不能凭同一种子保证逐字节一致。课堂比较应直接使用仓库内固定素材；新生成的素材必须配套新真值表重新验收。
