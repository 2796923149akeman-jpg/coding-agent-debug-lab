# 应达到的结果与验收边界

这页的作用相当于成绩案例中“3 个测试通过、平均分 85.0、未填写 1 人”的说明。学生仍需让自己的 AI 编写和改进程序。

## 基础目标

| 检查项 | 应达到的结果 |
| --- | --- |
| 输入完整性 | 初始化后 205 个文件，字节与修改时间保持原样 |
| 输出数量 | 205 个输入对应 205 个输出，报告另存 |
| 内容完整性 | 无外来内容，各种内容的副本数与输入完全一致 |
| 异常文件 | 不能静默跳过；无法识别的文件单独保留并说明 |
| 图片归档 | 放进年月目录的图片必须能实际解码 |
| 日期归档 | 参考版通过原教师脚本 190/190 个带日期的唯一内容组检查 |
| 完全重复 | 固定素材存在 10 组字节相同的文件；给出证据并保留全部副本 |
| 清单 | 205 个来源各有一条可核对的去向，目标存在且字节一致 |
| 近重复（扩展） | 给出候选及相似度依据，由人确认，不自动删除 |

190 不是输入文件数量：原教师脚本按内容哈希分组，并只统计具有可检查日期的组。它不会把全部 205 个文件各计一次。

## 本次复测参考结果

在 Python 3.13.9、Pillow 12.0.0 环境中，使用原教师参考程序和本仓库初始化后的素材：

- 205 个文件全部保留，学生自检 C1～C4 全通过。
- 原教师日期验收 190/190；逐文件清单中的 205 个来源均能找到字节相同的目标。
- 参考版将 10 份完全重复副本单独保留，将 5 个无法识别文件单独保留。
- 参考版报告 10 对近重复候选；这只是该算法和阈值的运行结果，**不是要求学生必须输出的标准数量**。不同实现可能误报或漏报，需要人工复核。

学生可以采用不同的合理分类方法，但不得丢文件、覆盖或绕过验收。视频是分类练习的占位素材，本练习不验证视频播放和真实视频元数据。

## 教师如何进一步验收

先运行学生版自检与 `prepare.py --check`；再使用原课堂实操包中本地保留的 `03_工具/验收.py`，输入学生的原始目录、结果目录和教师的 `02_参考答案/答案索引.csv`。查看 C5 和“未通过”文本，不能只依赖原教师脚本的退出码。

还需人工复核清单、日期来源解释和近重复候选。原教师脚本有固定的年月目录识别约定，因此本练习统一采用 `YYYY-MM` 月份目录。

公开仓库不包含教师的答案索引、整理程序、正确归档结果或完整演示答案。两套练习统一提供学生起点、操作说明和验收目标。
