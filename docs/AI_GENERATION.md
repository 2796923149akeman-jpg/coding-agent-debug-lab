# 案例如何由 AI 辅助准备

## 成绩统计

成绩案例围绕空白成绩处理设计，使用三个测试明确正常数据、混合空白和全部空白时的行为。程序有意保留错误，便于观察复现、修复和复测的过程。详见 [生成与复现说明](../labs/01-grade-stats/docs/AI_GENERATION.md)。

## 照片整理

205 个文件是程序生成的教学素材。数据生成脚本使用 Python/Pillow 绘制渐变背景、色块和编号，构造截图、转存图片、重复内容及异常占位文件；它们不是真实个人相册。

`data/photos.zip` 保留固定输入，`manifest.json` 记录文件名、哈希和统一修改时间，供初始化和完整性核对。记录中不包含归档月份答案。

仓库的操作说明、素材初始化、自检加固和发布验证由 AI 辅助完成。材料未附完整生成对话和精确模型版本，因此不能独立还原最初每一步生成操作。以下提示词用于生成类似练习，不是原始对话逐字记录。

## 生成类似照片练习的提示词

在另一个空目录和新对话中使用，避免覆盖当前练习：

```text
请生成一个 Coding Agent 文件整理练习，使用纯合成素材，不使用真实个人照片。
交付练习目录和独立的验证目录，正确实现与真值表不要放进练习工作区。
练习包含 205 个扁平混杂文件、任务说明、只检查输入输出的自检工具。
覆盖带 EXIF 的图片、无 EXIF 的截图和转存图片、占位视频、完全重复与近重复、无效日期、打不开的图片和系统残留。
所有文件统一修改时间，并提供下载后可恢复时间的素材清单。
任务是按年月归档、保留每个副本、禁止覆盖输入、输出逐文件清单、为重复提供证据。
在独立验证目录实际执行参考实现，对照真值验证数量、逐内容副本数、图片解码和日期。
自检失败须返回非零退出码，缺失目录不能被视为通过，不得自动清空已有目录。
将真实运行输出与预期输出分开。不能执行时明确说明，不编造日志。
```

不同模型、Pillow 版本和字体环境生成的字节可能不同，同一种子不保证逐字节一致。比较不同 AI 的操作时，应使用本仓库的固定素材和相同验收要求。新生成的数据需配套新的验证记录。
