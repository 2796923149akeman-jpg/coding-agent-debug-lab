## 你要理解的 Coding Agent

在这些练习中，Coding Agent 是能在授权范围内读取项目、编辑文件、调用终端，并根据真实运行结果继续调整的 AI 编程助手。

```text
人说明目标与验收标准
        ↓
AI 读取文件 → 制定下一步 → 编辑或执行 → 观察真实反馈
                 ↑                         ↓
                 └──── 结果未达标，继续调整 ──┘
        ↓
人检查代码差异、结果与任务是否一致
```

关键不在于 AI 说“修好了”，而在于能看到它读了什么、改了什么、运行了什么，以及结果是否符合要求。[结合两个案例理解这个过程](docs/UNDERSTANDING_AGENTS.md)。
