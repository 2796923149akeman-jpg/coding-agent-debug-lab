# 应达到的结果与验收方法

本页给出照片整理任务的完成标准。你需要让 AI 编写整理程序，使用自检工具检查可自动验证的部分，再亲自核对日期、清单和重复报告。

## 基础目标

| 检查项 | 应达到的结果 |
| --- | --- |
| 输入完整性 | 初始化后 205 个文件，字节与修改时间保持原样 |
| 输出数量 | 205 个输入对应 205 个输出，报告另存 |
| 内容完整性 | 无外来内容，各种内容的副本数与输入完全一致 |
| 异常文件 | 不能静默跳过；无法识别的文件单独保留并说明 |
| 图片归档 | 放进年月目录的图片必须能实际解码 |
| 日期归档 | 月份与选定日期来源一致，使用 `YYYY-MM` 月份目录，并说明回退规则 |
| 完全重复 | 固定素材存在 10 组字节相同的文件；给出证据并保留全部副本 |
| 清单 | 205 个来源各有一条可核对的去向，目标存在且字节一致 |
| 近重复（扩展） | 给出候选及相似度依据，由人确认，不自动删除 |

## 1. 运行自动检查

在本案例目录执行，结果目录名称应与你实际使用的一致：

```sh
python self_check.py input output
python prepare.py --check
```

自检 C1～C4 应全为 PASS，输入核对也应 PASS。如果失败，保存真实输出，让 AI 修复 `organize.py` 后用新的结果目录复测。不要修改检查工具或素材。

## 2. 检查逐文件清单

打开 `reports/` 中的清单，确认有 205 个来源文件，每个来源都对应一个实际存在的输出路径。报告至少应包含来源、去向、分类、日期与日期来源。输出文件字节应与对应输入一致。

可以要求 AI 编写独立的核对脚本，并实际运行，检查来源是否遗漏、目标是否存在、哈希是否匹配。你仍需要检查该脚本比较了什么，避免只打印一个预设的“通过”。

## 3. 抽查归档日期

从不同日期来源各挑几份文件，让 AI 展示读到的元数据或文件名证据，并与你看到的实际内容对照：

- 有有效拍摄时间的图片：月份应与该时间一致。
- 日期来自截图或转存文件名：检查解析出的年月是否合理。
- 使用时间戳：按练习约定的 UTC+08:00 解释。
- 日期无效或缺失：报告中应说明采用了什么回退方法；修改时间不等于已知的真实拍摄时间。

全部输入的修改时间相同，不能简单按修改时间把整个素材集都归入同一个月。抽样通过也不等于逐项验证了全部日期，记录你实际检查的范围。

## 4. 检查重复与无法识别文件

完全重复应提供字节哈希证据，并保留所有副本。本素材包含 10 组完全重复文件；不能为了“去重”而删除副本。

无法识别文件应单独保留并说明。参考流程复测时有 5 个文件被归为无法识别，你可以采用不同的合理分类，但不能将它们丢弃或作为可解码照片归档。

近重复只提供候选，不规定必须输出多少对。不同算法与阈值可能误报或漏报，需要打开图片人工判断。视频为分类练习占位素材，本练习不验证视频能播放。

## 5. 保存结论与边界

在练习记录中保存运行输出、清单检查、日期抽查及人工判断。自检通过仅表示它覆盖的指标通过；把全部文件复制到一个文件夹，仍不满足按年月整理的任务。

本仓库提供练习起点、操作说明和验收目标，不包含正确代码、答案索引或整理成品。
