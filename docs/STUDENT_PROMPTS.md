# 实操提示词：按两个案例的顺序操作

先按 [上手指南](GETTING_STARTED.md) 下载、解压并确认环境。每段提示词完成后，先检查 AI 的真实操作和结果，再发送下一段。

## 实操一：成绩统计纠错

进入 `labs/01-grade-stats` 并将其设为 AI 工作区，使用 [成绩案例四段提示词](../labs/01-grade-stats/docs/STUDENT_PROMPTS.md)：读项目 → 复现报错 → 修改并复测 → 人工解释。

## 实操二：照片整理

切换到 `labs/02-photo-organizer`，安装依赖并运行 `prepare.py`，新开对话，使用 [照片案例四段提示词](../labs/02-photo-organizer/PROMPTS.md)：观察与计划 → 编写第一版 → 自检和迭代 → 人工验收。

## 两个案例都要坚持

- 要求真实执行记录；不能执行时说明限制，由你运行并回传结果。
- 不修改测试、素材和验收工具来制造通过。
- 明确当前目录、允许修改的文件和完成标准。
- 要求解释代码与业务结果，不能只接受“已完成”。

操作完成后，用 [理解指南](UNDERSTANDING_AGENTS.md) 对照发生过的工具调用和反馈循环。
