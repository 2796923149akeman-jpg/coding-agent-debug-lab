# 02 照片整理

本案例练习让 AI 从需求出发创建文件整理程序，并根据真实运行结果改进和验收。首次使用请先阅读 [同学上手指南](../../docs/GETTING_STARTED.md)。205 个文件都是合成教学素材，包含模拟照片、截图、视频占位文件，以及刻意保留的异常输入。不要用个人相册替换本练习数据。

## 准备（在本案例文件夹运行）

如果终端还在成绩目录，先执行 `cd ../02-photo-organizer`；同时把 AI 工作区切换到本案例，并新开一次对话。

```sh
python -m pip install -r requirements.txt
python prepare.py
```

`prepare.py` 校验素材压缩包、解出 205 个文件到 `input/`，并恢复练习所需的统一修改时间。Git 和不同解压软件不会可靠保留该时间，因此所有同学都应执行此步骤。初始化只创建新的输入目录，不覆盖已有文件。

在本目录已有正确 `input/` 时，可以重复运行以核对内容与时间；如内容被改动，工具会停止。要重新练习，请下载并解压到一个新目录。所有文件的修改时间统一为 `2025-06-01 10:30:00 +08:00`；时间戳的解释统一采用 UTC+08:00。

## 任务

让 AI 在本目录创建 `organize.py`，实现：

1. 将 `input/` 按拍摄年月归档到 `output/`；照片采用 `YYYY/YYYY-MM/`。截图、视频可单独分类，其年月目录仍使用 `YYYY-MM`。
2. 找出字节完全相同的文件，保留每个原始副本；如需隔离，放到 `_重复/`。近重复只列候选供人判断。
3. 不能识别或应排除的文件也要保存在明确的目录中，不能静默丢弃。
4. 在 `reports/` 生成逐文件清单，至少包含来源、去向、分类、日期与日期来源，以及重复判定依据。
5. 输入保持原样，输出不得覆盖已有文件。重复运行应拒绝非空目标目录或采取明确的无覆盖策略。

**205 个输入文件必须对应 205 个输出文件，各种内容出现的次数也必须一致。** 报告放在 `reports/`，不能混进 `output/`，否则验收会把报告算作外来文件。

学生版没有给出 `organize.py`，编写它就是任务本身。按 [分步提示词](PROMPTS.md) 指挥 AI 先观察数据、提出方案，再实现和运行。

## 运行与验收

与 AI 约定以下接口后运行：

```sh
python organize.py input output reports
python self_check.py input output
python prepare.py --check
```

`self_check.py` 检查数量、外来内容、每种字节内容的副本数、归档图片是否能解码。通过退出码为 0，不通过为 1；路径或运行环境错误为 2。

`prepare.py --check` 核对输入文件的内容和修改时间未被改变。缺少输入时仅报错，不生成文件。

**自检通过不代表整个任务完成。** 自检不评分日期准确性、报告完整性和近重复质量，也不验证视频能播放。还要检查每个来源在清单中的去向，并按验收说明人工抽查月份和重复报告。不能把文件全部原样拷到一个文件夹后，仅凭自检通过宣称完成。

详见 [应达到的结果与验收边界](EXPECTED_RESULTS.md)。这里只公布验收目标，不提供整理后的成品或正确代码，与成绩案例的发布方式一致。

## 完成后提交什么

- `organize.py` 和简要运行说明；
- 自检输出及 205 → 205 的证据；
- `reports/` 中的清单和重复报告；
- 一段说明：遇到了什么真实错误，如何迭代，哪些结果还需要人判断。

默认在本地保留，不需要把个人信息或聊天记录提交到公开仓库。使用 [练习记录模板](../../docs/EXPERIMENT_REPORT.md)。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `data/photos.zip` | 205 个原始合成文件；作为数据资产保留，不是冗余发布包 |
| `data/manifest.json` | 文件名、大小、哈希、统一修改时间；不含日期答案 |
| `prepare.py` | 无覆盖初始化与原始输入核对 |
| `self_check.py` | 学生自检；独立于学生编写的整理代码 |
| `requirements.txt` | Pillow 依赖；本次实际验证为 12.0.0 |
| `PROMPTS.md` | 分步提示词 |
| `tests/test_tools.py` | 初始化和自检工具的回归测试 |

工具测试命令：`python -m unittest discover -s tests -v`。这只验证配套工具，不表示你的整理任务已完成。

## 这个案例如何帮助理解 Coding Agent

观察 AI 怎样把需求拆成行动、怎样检查真实数据、怎样创建并运行程序，再怎样依据自检结果改进。完成后对照 [理解指南](../../docs/UNDERSTANDING_AGENTS.md)，解释与成绩案例共同的工作循环，以及本任务需要增加的人工判断。
